Speak Nigeria • One Word at a Time

A free Progressive Web App designed to help anyone learn the three major Nigerian languages — Hausa, Igbo and Yoruba — using English as the bridge language.

Features include interactive lessons, quizzes, matching games, memory cards, word puzzles and translation exercises.
